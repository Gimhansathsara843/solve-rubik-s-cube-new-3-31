How to Use the Rubik's Cube Solver

  1. Select a color from the palette at the top
  2. Click on tiles in the 3D cube to apply the selected color
  3. Rotate the view using the rotation buttons to access all faces
  4. Click "Scramble Cube" to randomly mix the cube
  5. Click "Solve Cube" when you've configured your cube
  6. Watch the animation as the cube solves itself
  7. Use "Reset Cube" to start over with a solved cube

Tip: Make sure each face has a single solid color for accurate solving.
